# VR Museum of Anything

Intended as a generic Unity VR/AR museum shell. Currently an unmodified Unity AR Foundation Samples scaffold — no museum-specific code has been added yet.

Status: early scaffold / placeholder — no implementation yet.

## What's actually in the repo

- A Unity project (editor version `2020.3.11f1`) configured with AR Foundation 4.0.12 (ARCore, ARKit, Magic Leap, Windows MR) — see `Packages/manifest.json`
- Two stock AR Foundation sample scripts under `Assets/ExampleAssets/Scripts/` (`AnchorCreator.cs`, `ARFeatheredPlaneMeshVisualizer.cs`)
- Sample/blank scenes (`Assets/ExampleAssets/Scenes/SampleScene.unity`, `Assets/Scenes/BlankAR.unity`)

No museum logic, artifact loading, or navigation has been implemented yet.
